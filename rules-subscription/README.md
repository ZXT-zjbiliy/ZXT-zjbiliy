# Rules subscription

These files contain routing rules only; they do not contain proxy nodes, UUIDs, passwords, or server addresses.

## v2rayN

Use this custom routing rules URL:

https://raw.githubusercontent.com/ZXT-zjbiliy/ZXT-zjbiliy/main/rules-subscription/rules-v2rayn.json

The rules block ads, send private and China traffic direct, and send remaining traffic through the `proxy` outbound.

## Clash Verge Rev / Mihomo

Rules list:

https://raw.githubusercontent.com/ZXT-zjbiliy/ZXT-zjbiliy/main/rules-subscription/rules-clash-verge.txt

Add these rules to the existing profile's rules. Replace the final `代理` target with the proxy group name used by that profile. This is a rules list, not a full Clash profile.
